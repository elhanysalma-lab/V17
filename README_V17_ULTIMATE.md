# Noury Pixar V17 Ultimate Studio
تم دمج تأثيرات أهم إضافات Godot مباشرة في الكود ليعمل المسار الآلي بأقصى جودة سينمائية دون تعقيدات تثبيت الإضافات الخارجية:

1. **`shaders/cutout_3d.gdshader`**: (يغني عن Laigter و Wind Shader). يقوم بتحريك ملابس الشخصيات مع الرياح، ويولد خرائط ظل (Normal Maps) وهمية لتتفاعل الصورة الـ 2D مع أشعة الشمس وتظهر كشخصية 3D منتفخة.
2. **`render_scene.gd`**: يحتوي على خوارزمية (ProtonScatter Lite) لتوليد غابة طبيعية عشوائية تحيط بالشخصيات مع كل رندر، بالإضافة إلى كاميرا تتبع سينمائية (PhantomCam Lite).

## طريقة الاستخدام
هذا المشروع مصمم ليكون ذاتي التشغيل (Automated) بالكامل في مسار V15/V16 الخاص بك.
