# 🎬 Pixar AI Studio Auto-Pipeline
نظام متكامل وآلي بالكامل لإنتاج قصص أطفال بأسلوب الرسوم المتحركة ثلاثية الأبعاد (Pixar-style) باستخدام تقنيات الذكاء الاصطناعي ورفعه تلقائياً على يوتيوب.

## ⚙️ كيف يعمل؟
1. **Gemini**: يكتب القصة، يولد الحوار، ويصمم الـ Prompts للصور والفيديو.
2. **ElevenLabs**: يقوم بتحويل الحوار إلى أصوات بشرية درامية للأطفال.
3. **Banana.dev (Flux)**: يولد الإطارات الرئيسية والصور بدقة 4K وبنسبة 16:9.
4. **Kling AI**: يقوم بتحريك الصور وجعلها مشاهد سينمائية حيوية.
5. **MoviePy**: يقوم بمزامنة الشفاه (الصوت مع الصورة) وعمل المونتاج النهائي للفيلم.
6. **YouTube API**: يرفع الفيديو تلقائياً على قناتك فور اكتماله.

## 🚀 طريقة التثبيت في GitHub (Deployment)
1. قم برفع جميع محتويات هذا المجلد (بما فيها مجلد `.github`) إلى مستودعك الخاص (Repository) على GitHub.
2. اذهب إلى إعدادات المستودع **Settings** -> **Secrets and variables** -> **Actions**.
3. قم بإضافة المفاتيح السرية التالية (New repository secret):
   - `GEMINI_API_KEY`: مفتاح واجهة Gemini.
   - `ELEVENLABS_API_KEY`: مفتاح ElevenLabs للأصوات.
   - `BANANA_API_KEY`: مفتاح Flux عبر منصة Banana.
   - `KLING_API_KEY`: مفتاح Kling AI للتحريك.
   - `YOUTUBE_CLIENT_SECRET`: محتوى ملف الـ JSON الخاص بتصاريح يوتيوب للرفع الآلي.

## ▶️ التشغيل اليدوي والآلي
- النظام مبرمج ليعمل تلقائياً **كل يوم جمعة** لتوليد ونشر حلقة جديدة.
- لتشغيله يدوياً في أي وقت: اذهب إلى تبويب **Actions** في GitHub -> اختر **Auto AI Pixar Studio Pipeline** -> اضغط **Run workflow**.
